### DESKRIPSI PROYEK

Pada Pertemuan 10, saya membuat website **Selaras Coffee**, yaitu website yang menampilkan informasi mengenai kedai kopi dan berbagai pilihan menu yang tersedia.

Website ini dibuat menggunakan HTML, CSS, dan Bootstrap 5. Tampilan website menggunakan perpaduan warna cokelat dan warna netral agar sesuai dengan konsep kedai kopi.

Website ini memiliki beberapa bagian, seperti navbar, halaman beranda, pilihan menu, informasi menu, form pemesanan, modal, dan footer.

### FITUR WEBSITE

1. **Navbar** – Menampilkan nama Selaras Coffee serta menu Beranda, Menu, dan Pemesanan.
2. **Header** – Menampilkan ucapan selamat datang dan deskripsi singkat mengenai Selaras Coffee.
3. **Profile Pengunjung** – Menampilkan gambar dan informasi pengunjung.
4. **Alert Promo** – Menampilkan informasi promo spesial.
5. **Pilihan Menu** – Menampilkan empat kategori, yaitu Kopi, Non-Kopi, Minuman Segar, dan Makanan.
6. **Menu** – Menampilkan informasi mengenai pilihan menu kopi, non-kopi, dan makanan.
7. **Modal Detail** – Menampilkan informasi tambahan mengenai menu.
8. **Form Pemesanan** – Menyediakan kolom nama, email, pilihan menu, metode pemesanan, dan catatan pesanan.
9. **Modal Konfirmasi** – Menampilkan konfirmasi sebelum pesanan dilanjutkan.
10. **Footer** – Menampilkan informasi hak cipta Selaras Coffee.

### TEKNOLOGI YANG DIGUNAKAN

- **HTML** – Digunakan untuk membuat struktur halaman website.
- **CSS Eksternal** – Digunakan untuk mengatur warna, ukuran, jarak, dan tampilan website.
- **Bootstrap 5** – Digunakan untuk membantu membuat layout dan komponen website agar lebih responsif.

### PENERAPAN BOOTSTRAP 5

Beberapa komponen Bootstrap yang digunakan dalam website ini:

- **Navbar** untuk membuat navigasi website.
- **Container** untuk mengatur posisi konten.
- **Grid System** untuk mengatur susunan card dan form.
- **Card** untuk menampilkan kategori menu.
- **Alert** untuk menampilkan informasi promo.
- **Modal** untuk menampilkan detail dan konfirmasi pesanan.
- **Form Control** untuk mengatur kolom input.
- **Button** untuk membuat tombol aksi.
- **Spacing Utility** untuk mengatur jarak antarbagian.

### PENERAPAN CSS

CSS eksternal terdapat pada file `css/style.css`.

Beberapa penerapan CSS yang digunakan:

- `background-color` untuk mengatur warna latar belakang.
- `:root` untuk menyimpan variabel warna dan ukuran.
- `.brand-navbar` untuk mengatur warna navbar.
- `.section-label` untuk mengatur tampilan label bagian.
- `.profile-box` untuk mengatur posisi foto profil.
- `.dashboard-card` untuk mengatur tampilan card.
- `.btn-brand` untuk mengatur warna tombol.
- `box-shadow` untuk memberikan efek bayangan.
- `border-radius` untuk membuat sudut elemen lebih melengkung.
- `object-fit: cover` untuk mengatur gambar agar sesuai dengan ukuran yang tersedia.
- `@media` untuk menyesuaikan tampilan pada ukuran layar yang berbeda.

### RESPONSIVE DESIGN

Website menggunakan Bootstrap Grid System dan media query agar tampilannya dapat menyesuaikan ukuran perangkat.

- **Desktop:** Kategori menu ditampilkan dalam empat kolom.
- **Tablet:** Susunan kategori menyesuaikan ukuran layar menjadi dua kolom.
- **Smartphone:** Kategori menu ditampilkan dalam satu kolom.

Selain itu, navbar menggunakan fitur collapse Bootstrap agar navigasi tetap mudah digunakan pada layar yang lebih kecil.

### FORM PEMESANAN

Form pemesanan menyediakan beberapa kolom yang dapat diisi oleh pengunjung, yaitu:

- Nama Pemesan
- Email
- Pilihan Menu
- Metode Pemesanan (Take Away atau Dine In)
- Catatan Pesanan
- Persetujuan Data Pemesanan

Form ini masih berupa tampilan frontend dan belum terhubung dengan database atau sistem pemrosesan pesanan.

### PENGUJIAN WEBSITE

Pengujian dilakukan melalui browser untuk memastikan setiap bagian website dapat ditampilkan dengan baik.

Beberapa bagian yang diuji:

1. Navbar dapat digunakan untuk berpindah ke bagian halaman.
2. Alert promo dapat ditampilkan dan ditutup.
3. Kategori menu dapat ditampilkan dengan gambar.
4. Tombol Detail dapat membuka modal.
5. Form pemesanan dapat menerima input.
6. Tombol Kirim Pesanan dapat membuka modal konfirmasi.
7. Tampilan website dapat menyesuaikan ukuran layar.
